Category Unification

One-time reconciliation: matches Planner's Trivia themes and Venue Menu's browsing categories back to the real game-content libraries (trivia/categories and bingo/landing/categories), so there's one record per category instead of three. Nothing is deleted here — this only copies fields forward and re-points references. All five apps (Planner, Trivia Admin, Bingo Admin, Venue Menu admin, and the public Venue Menu) already read/write these unified docs directly — this page is the step that actually merges everything that's still scattered into them. Run Step 1, then Step 2, then Step 3, in order, all the way through (including the "Create All Unmatched" buttons for anything with no automatic match) — that's what makes a theme or category that only ever lived in one app start showing up everywhere it should.
⚠ Some Planner "themes" tagged for a round-3 / coordinating slot are actually Bingo categories referenced by name, not Trivia categories. Anything that looks like this is flagged "Ambiguous" below — pick the real target manually rather than trusting an auto-match.
1
Match Planner Themes to Real Categories
Every entry in trivia/planner/themes, matched by name to trivia/categories (or bingo/landing/categories for coordinating-music themes). Confirm or override each one, then apply.
2
Match Venue Menu Listings to Real Categories
venueMenuCategories docs tagged Trivia or Bingo, matched to the same real category libraries. Their venue-facing fields (description, banner, published tabs) get copied onto the matched record under a venueMenu field — nothing else on that record is touched.
3
Re-point Every Scheduled Gig
Only run this after Step 1 is fully applied (every theme matched, no ambiguous rows left). Rewrites every gig's themeId/round3ThemeId to point at the real category id instead of the old theme id, and tags which collection it lives in (themeCollection). themeName/round3Name are left untouched, since the rest of Planner already displays from those. Old theme docs are left in place — nothing is deleted.
